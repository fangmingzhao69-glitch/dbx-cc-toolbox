# CC 工具箱路线 B 改造与实施方案

2026-11-20。基线为已发布的 0.2.4 和工作区中的 XML 与注册表原型。本方案依据《路线 B 架构重构方案》及对现有代码的复核重新制定。

## 改造边界

- 保留 JSON 编辑器、页签、筛选、表格和会话机制。现有工具继续使用原来的入口、权限、数据格式和设置键。
- 将工具清单集中到静态注册表。外壳负责导航、建立容器、挂载和故障提示。工具负责自己的模板、交互和状态。
- 最近确认的 XML 格式化与校验问题、CSV 重复主键漏报、离线枚举与正则漏报作为独立的数据正确性改动验收。
- XML 支持常用文档、命名空间前缀、注释、CDATA 和处理指令，禁止 DTD。保留混合内容及 `xml:space="preserve"`，限制输入大小、层级和节点数。Escape 工具另行立项。

## 目标结构和契约

| 部位 | 责任 |
|---|---|
| `ui/index.html`、`ui/js/app.js` | 保留 JSON 核心、工作台外壳、公共浮层、宿主关闭与会话保存 |
| `ui/js/registry.js` | 静态导入工具，按一份清单生成菜单和面板，挂载时分别捕获异常 |
| `ui/tools/<id>/` | 工具入口和静态 JS 模板，私有样式放一起，共用样式留在全局 |
| `ui/shared/` | CSV 和 SQL 纯函数、宿主桥接、异步偏好读写 |

工具通过 `mount(ctx, panel)` 在第一次打开时挂载，返回可选的 `show()`、`hide()` 和 `dispose()`。切换工具保留已挂载 DOM 和内存状态。画板可在隐藏时暂停尺寸监听，发票仍保留原稿和打印状态轮询。工作台关闭时调用 `dispose()`。重试失败模块时重建它的面板内容。静态模块保持顶层无 DOM 和宿主操作，文件缺失或语法错误交由打包和启动测试发现。

`ctx.settings` 沿用启动后可同步读取的设置缓存，`ctx.preferences` 提供可等待的持久化读写，用于发票模板和历史，原键和值格式兼容。`ctx.showTool(id)` 用于工具间跳转。`ctx.saveFile` 通过宿主保存文本或图片，取消时返回取消状态。

## DBX 资源加载

正式包通过 DBX 资产协议加载静态 JS。模块模板随 JS 一起交付，样式在入口 HTML 的 `<head>` 预先声明，由宿主内联。插件不依赖运行时 `fetch()` 读模板，也不动态插入外链 CSS。打包测试覆盖无 `allow-same-origin`、`connect-src 'none'` 和禁止外链样式的宿主行为。

## 实施顺序

1. **外壳与共享层**。统一注册，分离挂载与切换，抽取 CSV、SQL、宿主桥接和存储接口。
2. **逐工具迁移**。搬迁模板、事件和私有样式，保留 DOM ID。确认发票、画板及文件型工具跨面板切换保留状态，移除旧的 `tools.js`。
3. **数据正确性**。XML 使用当前原文格式化和导出，校验重复属性、实体及资源上限。CSV 对重复主键给出可定位的错误。离线枚举与正则使用明确的字段选择，整列非法时仍报告错误。
4. **回归和发布**。执行纯逻辑、各工具界面、严格宿主沙箱和发票真实侧车测试。发布 Windows x64 签名包，更新自托管目录，并从公开地址重新下载验证 SHA-256。

## 验收

- 所有菜单与面板一一对应，已有入口可用。故障模块给出重试入口，其他工具仍可切换。
- 严格宿主沙箱下 XML 有正确布局，格式化保留混合文本与当前输入。包含重复属性或非法实体的样例判定无效。
- 画板、CSV、发票往返切换保留当前内容。发票历史和模板沿用现有存储键，发票侧车调用和打印任务继续可用。
- CSV 重复主键和离线规则全量不匹配都有明确结果。回归用例覆盖这些行为，而非仅检查节点存在。
- 按 `AGENTS.md` 完成线上签名发布，确认 DBX 仓库可见新版本。
