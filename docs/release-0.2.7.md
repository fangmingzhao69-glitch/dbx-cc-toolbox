# CC 工具箱 0.2.7

本版改善常用交互，并修复可能造成误判、精度丢失或覆盖编辑内容的问题。适用于 Windows x64。

- 侧边栏可查找工具。在工作台内用 Ctrl+Shift+K 定位搜索框，Enter 打开首个匹配项。
- CSV/TSV 预览可搜索全部数据并翻页，保留原始行号。比对支持共同表头选主键、增删列差异和仅看差异。重复或空主键、错误引号及列数不一致会明确报错。
- JSON 内容比对保留大整数精度并比较深层字段，区分结构差异与原文行差异。可以在比对输入区按 Ctrl+Enter 开始比对。
- SQL 导入保留大整数、长小数和 CSV 前导零。在目标数据库不能准确表示数值时，生成文本列以保留原始数据。支持解析同表、同字段的多条 INSERT，快速建表生成单一复合主键约束。
- 修改输入后旧 SQL、校验结果和 CSV 差异不再可复制或导出。在线校验支持刷新连接，按生成的查询逐项执行。
- DBX 送来新 JSON 时，已有内容留在原页签，新内容进入单独的「DBX 上下文」页签。

在 DBX 插件中心刷新 `cctoolbox.local`，再到已安装插件更新，原仓库信任设置继续适用。
