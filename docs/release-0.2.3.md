# CC 工具箱 0.2.3

本版更新发票打印工具，适用于 Windows x64。

- 批量导入 PDF 或图片，支持选择文件夹、按内容去重、调整顺序、逐项删除和指定页码。分块传输避免较大文件超过 DBX 单次请求限制。
- 原稿和排版预览支持翻页、旋转、缩放。排版支持横纵向、自定义纸张、四边边距、间距、裁剪线和套打偏移。
- 预览和打印共用毫米坐标与排版逻辑。可保存、应用或删除打印模板，也可设置份数和质量。
- 显示任务提交进度、系统队列状态和最近 50 条打印记录。队列未确认完成时，界面会提示查看系统打印队列。

在 DBX 的插件仓库设置中刷新 `cctoolbox.local`，再从已安装插件更新 CC 工具箱。继续使用原有仓库信任设置。

已通过 Windows 侧车和 DBX 沙箱模拟测试，覆盖分块传输、PDF 选页、图像旋转、套打预览及打印失败反馈。实体打印机的出纸位置仍需在实际设备上校准。
