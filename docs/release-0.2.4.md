# CC 工具箱 0.2.4

本版改善 JSON 解析页的编辑和阅读体验，适用于 Windows x64。

- 粘贴合法 JSON 后自动缩进并生成表格，保留大整数和指数的原始写法。可用 Ctrl+Z 撤销粘贴，非法 JSON 保留原文并显示解析错误。
- 每个页签独立保存分割线的位置，重新打开工作台仍可恢复。双击仅重置当前页签。
- 展开后的嵌套数组可独立滚动。点击「单独查看」可在整个右侧表格区浏览，返回时保留原表展开状态和滚动位置。
- 表头和行号在滚动时保留可见，长文本可换行，深色主题中的表格文字使用高对比度配色。

在 DBX 的插件仓库设置中刷新 `cctoolbox.local`，再从已安装插件更新 CC 工具箱。继续使用原有仓库信任设置。
