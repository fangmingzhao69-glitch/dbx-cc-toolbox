# CC 工具箱 0.2.5

适用于 Windows x64。此版本实施了路线 B，将工具箱拆成由同一注册表管理的 12 个工具。工具首次打开时初始化，切换面板会保留当前内容，单个工具挂载失败时可以重试。

- 新增 XML 树形查看、原文定位、格式化、校验和 CSV 导出。格式化以编辑器当前原文为准，保留混合文本与 `xml:space`，校验会报告重复属性和非法实体。解析器支持 XML 1.0，禁止 DTD。
- CSV 按主键比对查到重复键时显示文件和行号，避免覆盖记录后误报无差异。
- 离线枚举与正则校验可选字段，整列不符合规则时会报告每条记录。
- 画板 PNG、CSV 差异和离线校验报告通过 DBX 保存文件接口导出。切换工具不影响发票工作区和打印状态。

在 DBX 的插件仓库设置中刷新 `cctoolbox.local`，再到已安装插件更新。仍使用原有的仓库信任配置。

实现依据见 [路线 B 改造与实施方案](route-b-implementation-plan.md)。
