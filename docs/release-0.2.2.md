# CC 工具箱 0.2.2

本版修复 JSON 模块的数值保真、原文定位、页签状态与导出，并补齐 DBX 沙箱中的存储和筛选适配。

- 保留大整数、长小数和指数原始字面量，格式化和压缩不再改变数值。
- 修复特殊键、转义键的原文定位；筛选与重排只对来源和内容均可靠的节点提供原文跳转。
- 修复快速切换页签显示旧表格、非法输入残留筛选结果及 Tab 缩进未保存。
- 正确显示根值 0、false、null 和空字符串；缺失字段不读取原型链。
- CSV 中嵌套对象保留 JSON 内容。
- 嵌套按需展开，数组每页 100 行，宽表每次 50 列；恢复展开、分页及嵌套滚动。
- DBX 内通过受限 C# 侧车解释器执行高级筛选，使用宿主接口导出文件，分块传输和原子保存大文档。
- 修复侧车中文 UTF-8 编码；页签支持沙箱内重命名。

本版清单声明工具箱实际调用的存储、连接列表及只读数据权限。数据库建表和导入工具生成 SQL；数据查询仅使用宿主只读 API。清单 source 指向本版源码 tag，发行包不包含 PDB。

验证：原有 50 项界面检查、14 组核心检查、8 组真实侧车检查和 15 组沙箱/桥接检查通过。单文件自包含侧车同样通过侧车和沙箱检查。

更新：在 DBX 的插件仓库设置中刷新 `cctoolbox.local`，再到已安装插件更新 CC 工具箱。仓库地址和签名 Key ID 不变。
