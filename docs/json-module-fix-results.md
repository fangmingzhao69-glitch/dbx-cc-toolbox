## 当前边界

- 新构造对象、聚合和重复标量不具备可靠的原对象身份时，显示结果但不允许猜测原文位置。
- 不保真的 Number 输入、重复字段文档可以浏览与格式化；高级 JS 筛选会明确拒绝转换。
- 对象数组内的重复字段不能无歧义地映射为 CSV 列，会明确报错；JSON 原文和节点仍完整保留。
- 解析上限：20×1024×1024 个 UTF-16 码元、50 万节点、256 层。自动恢复最多 50 个页签，文件总量上限 40MiB。
- DBX 侧车筛选限制：2 秒、100 万语句、128MiB 解释器内存、128 层调用递归；结果文本上限 4×1024×1024 个 UTF-16 码元。对象来源索引最多 10 万个容器。
- 主线程仍负责有界解析；本轮优化重点是限制 DOM、分页及按需渲染，未宣称任意体积输入都不会阻塞。
- 真实 DBX 桌面程序内的新包安装、工作台关闭握手及文件对话框人工验收待完成；自动保存状态为“已保存”前，不保证强制退出能保留最新输入。

## 运行方式

在插件工程目录运行：

```powershell
npm test
npm run test:json:sidecar
npm run test:json:host
```

既有界面测试需要先启动本地静态服务：

```powershell
node _serve.cjs ui 5199
# 另一个终端：
npm run test:ui
```

测试已发布 exe 可在当前终端设置 `CC_JSON_SIDECAR_EXE` 为发布产物绝对路径，再运行 `node test-json-sidecar.mjs` 或 `node test-json-host.mjs`。测试恢复文件只写入自动生成的临时目录，结束后清理。
